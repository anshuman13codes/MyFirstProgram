## Calculator - My First C++ Project 🧮

My first real program built in Class 8!
A simple calculator made in C++ that can do maths
What it can do
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

 How I made it
I used `cin` to take numbers from user, `if-else` to check which operation, and `cout` to show the answer.

 How to run
1. Open `MyFirstProgram.slnx` in Visual Studio
2. Press F5 to run
3. Enter 2 numbers and choose operation
